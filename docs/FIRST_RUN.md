# 第一次使用 OLED 编辑器

目标：做一页文字，调整位置，保存后重新打开，再导出图片。只进行电脑预览，不接开发板。

## 1. 打开通用编辑器

按 [README 的源码启动步骤](../README.md#快速启动windows)启动。打开终端给出的地址，进入“通用编辑器”，或在地址后加 `/studio`。不要使用过去某次启动的旧端口。

## 2. 做一个简单页面

1. 新建项目，使用一个未用过的保存名称，例如 `first_oled`。
2. 选中初始文字，将内容改为 `HELLO`，X 设为 0、Y 设为 0。检查左上角的预览。
3. 再尝试输入“你好”。若当前严格字库模式提示缺字，记录缺字；支持中文补充预览时可切换查看，但补充预览不能替代目标字库验收。
4. 点击文字，确认选框和属性对应同一元素；拖动或修改坐标，观察位置。故意移到屏幕边缘，查看越界提示，然后移回。
5. 保存项目，重新打开，确认文字和位置仍在。
6. 导出 PNG，检查图像为 128×64。预览放大不改变屏幕实际像素数。

## 3. 再试一个交互

按[通用编辑器指南](../oled_preview/STUDIO_GUIDE.md)的数值输入示例，绑定变量 `value`，让 KEY1 打开弹窗，旋钮修改临时值，KEY1 确认、KEY2 取消。屏幕上的模拟按键不会操作实体硬件。

设计初始值与模拟运行值分开：不要把试玩后的数值当成已经保存的新初始值。

## 4. 导出后怎么办

PNG 用于展示；已保存项目用于继续编辑；C 导出文件用于审阅和工程接入。导出不会自动更新 Keil 工程或烧录。

进入硬件接入前，先看 [README 的接入流程](../README.md#从设计到开发板)，核对驱动、字库、变量与按键绑定，再分别完成编译和实物验证。

## 5. 常见问题与反馈

- 页面打不开：保持服务终端运行，使用这一次输出的地址。
- 缺少依赖：在仓库根目录，使用 README 中同一虚拟环境的 Python 安装 requirements。
- 中文缺字：保留提示，检查字库模式和 Windows 字体，不把占位效果当成真实字模。
- 保存冲突：重新打开最新项目或另存副本，避免覆盖其他窗口或 MCP 的修改。
- 套装与独立版找不到相同项目：两处数据并不自动同步，请先确认自己运行的是哪一版。

通过[试用反馈](https://github.com/9595846/oled-ui-workbench/issues/new/choose)提交版本、启动方式、操作步骤、预期与实际结果；截图和设计资料请先移除个人信息。
